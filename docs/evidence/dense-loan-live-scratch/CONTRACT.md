# Private point-domain live scratch

Source-only candidate from a231 plus the owner123 fixture correction (18e479).
The ordinary authenticated funded planner now builds only its temporary live
sets as bit words. Seeds, parent temporary unions, aliases, bindings, terminal
roots, CFG construction and every public plan carrier retain their old policy.
The full prior AVL liveness functions and complete independent old planner
remain compiled under test; no original algorithm or diagnostic comparison is
removed. Membership is the only generalized overlap-wrapper interface.

A normal CFG already proves at most 4096 point identities. The first actual
insertion lazily allocates ceil(actual point count / 64) exact u64 slots. Empty
sets allocate no words. A malformed larger u16 key grows the words through that
key, retaining the old set's membership, without a new logical admission bound.
The constructor prepays two actual Nodes carriers and its Result. Growth
prepays the actual Vec and Result receiving carriers, then the existing exact
storage producer prepays the entire new array before allocation/copy; existing
backing stays paid until replacement and never refunds its cumulative debit.
The iterator prepays its Keys and Result carriers and yields ascending integers.
It changes no canonical plan order, sorts no attached plan and grants no payer.
Each fallible operation authenticates the same held CfgReservation, including
zero, spare capacity, duplicate insertion and removal. Allocation/capacity
refusals retain the existing typed sticky publication protocol.

The complete liveness/edge loops retain all original logical WorkCounter calls,
short-circuit order, LIFO seed/pending order and work limit. Bit scanning/copying
implements that unchanged logical set interface; it adds no quota or work
credit. Malformed growth remains finite over all u16 keys. Actual byte refusal
boundaries deliberately change with real representation; sparse sets can cost
more than AVL. No universal efficiency, exclusive failure cause or application
fit is claimed. The normalizer and unchanged primitive-String application owners
must qualify the combined implementation before any such result is reported.

New owners compare the complete prior liveness rows and edge vectors over every
logical work frontier; complete old/current ordinary plans and full late
six-field diagnostics run inside a single allocation-to-last-Drop observation.
Separate receiver owners cover keys 0/64/65/4095/65535, duplicates, ordered
extraction, all actual allocation/receiving boundaries, exact/short/zero,
foreign/restored sticky rejection and no post-refusal allocation. These are
source-authored controls, pending Rust compilation and execution by ROOT.
