# Typed structural replay refusals v1

Status: source checkpoint; current-head owning execution qualification pending.

Audience: compiler contributors and reviewers.

Four private structural error families carry sealed data: repeated/unknown status
ExpressionId, noncontiguous slot index, and repeated StorageId. Shared immutable
identity handles and Copy indices preserve the original subject without rendering
inner text or the detailed function prefix. These receipts confer no admission,
lookup, current-source, or replay authority.

The selected and ordinary structural cores retain their original reservation,
insertion, lookup, mutation and first-error order. The paid scalar/lexical drivers
select the typed error policy. Existing earlier inventory, status-construction,
current-member and capacity refusals retain their original order and owned channel.
A typed atom does not cause an earlier full-driver failure to be skipped.

Preparation retains the first engine receipt and transfers its existing caller-paid
fixed report. Capacity Diagnostics retain their already-paid backing. Legacy
Diagnostic adapters render the exact detailed SPX-H006 text; that compatibility
boundary remains explicitly unfunded by the fixed report. Other semantic families
and successful whole-engine allocation inequalities remain open.

The owning tests distinguish receipt construction, legacy rendering, and a held
Session structural subphase. The latter observes acquisition through first error,
fixed-report transfer and Drop on the same reservation. Its constructor baseline
is measured separately; the additional unique storage-key debit is independently
derived from the existing B-tree layout policy. Zero additional allowance and
one-short controls preserve the first capacity receipt; exact allowance reaches
the typed structural failure. This is not full-driver candidate acceptance or
whole-pipeline physical funding evidence. Full-driver current-member error parity
and ordinary/selected detailed status errors remain separate controls.

## Partial transition refusal extension (OPT-781)

The same sealed protocol now retains four additional transition atoms: dead
call flag, double-consumed call flag, duplicate conditional variant epoch and
selected failure that differs from its pending edge. Each carries the exact
shared ExpressionId and, where relevant, Copy flag. Receipt construction clones
only the immutable identity handle; it renders no String. The legacy policy
continues to render the original complete H006 text synchronously.

The ordinary and selected transition drivers and the shared path walk select
this policy explicitly. Earlier child Diagnostics, capacity failures and all
unmigrated path errors move unchanged into the paid engine error sum. Check,
mutation and argument order are unchanged; in particular, conditional inventory
removal before a later duplicate refusal remains observable. The atoms confer
no permission to bypass source, current-member, schema or path validation.

Two owning bodies in `selected_entry::tests::transition_errors` compare saved
ordinary/selected cores for success, simultaneous hostiles and exact mutated
state, and observe actual acquisition through Session, mismatch receipt, paid
report transfer and Drop. The latter asserts no allocation or debit in that
specific mismatch subphase, same report/ledger pointers and sticky retry.
Source/leaf fixture creation and fixed active-ledger context are outside its
observer. This proves neither all transition allocations funded nor complete
Session/engine funding. These source-authored controls remain unexecuted.

## Selected-local Session successor (#781; source only)

The paid Session has a separate Context/owner/profile error policy for closed
static local refusals. Full old receivers and the raw earlier-current-member
Owned oracle remain independently compiled. New local errors acquire their full
receipt/sum/Result/optional control tuple before constructing shared-identity
receipt data; failed payment uses the existing prepaid budget Diagnostic.
The first retained receipt determines publication stage. Successful paths incur
no new fee only if independently asserted complete old/current receiving layouts
remain equal on the owning host. Those layout and physical/work controls are
pending; no portable equality or whole-engine funding is claimed.

Arbitrary child Diagnostics, including renewal census and work failures, retain
the original owned route. Detailed legacy rendering remains explicitly allocating.
The complete source packet, residuals and pending owners live in
`docs/evidence/selected-session-static-refusal-781/`.
