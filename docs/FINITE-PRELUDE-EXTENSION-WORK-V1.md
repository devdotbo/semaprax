# Finite Prelude Extension Work v1

Status: private source prototype, not compiled or executed. The actual ordinary
core-module receiver is wired for the first extension, Vec. All prior no-owner
APIs, other extension producers and complete old constructors remain independent.
No P, graph/cache schema, byte/physical cap or replay work bound changes.

This is a NEW compiler-internal finite work contract. There was no extension
remainder in the base producer: its local FixedSchemaPayer is consumed exactly
and dropped. Its two-type/nine-descriptor work_model and full old controls are
unchanged. No old account is reset or enlarged and no successful work bridge,
source-name filter, duplicate AST or process-global payload cache is introduced.

The core's live Invocation owns one optional VectorExtension and its typed work
receipt. Source verification still precedes activation. Only exact immutable
compiler AST prefixes of lengths 2,3,4,6,8,9,11 are accepted; a Vec view is offered
only for the exact third AST object and only when that existing selected prefix
contains it. Matching ID/name bytes in authored/decoded data grant nothing. This
prototype reuses ONLY Vec's complete parameter payload; other extension types
keep their old construction and selection. Prefix two does no extension work.

One ExtensionPayer is installed and its full actual Self/Result/WorkReceipt
carriers charged on the original raw byte callback before any extension work.
It has no heap and grants no authored/replay work. Its initial finite allowance
is derived from the producer's exact explicit sites:

```
entry + record-shape branch + parameter-shape branch + parameter initializer
+ len(actual Vec identity)
+ 2*len(actual Vec type name)
+ 2*len(actual parameter name)
= 4 + len(prelude::VEC_ID) + 2*len("Vec") + 2*len("T")
```

The two name passes copy UTF-8 then validate it, using the same paid helpers as
the base producer. Identity copying uses the established funded identity producer.
The only type shape admitted here is the actual compiler Vec record with no
fields and one parameter. The whole parameter vector, String/identity backing,
nominal Arc control/initializer/iterative scratch and all separately live output,
Option, Result and parameter initializers are acquired before construction.
Actual producer consumption must equal this derived bound. A schema producer
change requires source-contract qualification; no numeric margin or observed
allocation gap may be inserted. This finite allowance is separate from and
cannot finance base construction, module resolution or any downstream work.

The counter authenticates the same original byte owner with zero bytes before
each work debit. It retains its exact first FixedFailure<E:Copy>, including a
Detached byte tag across scope restoration, without requery or Clone. Refused
work records requested/remaining once. Invocation retains first ExtensionWork
separately from base Work and Bytes and never reconstructs either failed owner.
A successful cached module use still authenticates its actual receiving owner;
new metadata/map/string and payload-view carriers are paid in that module.
No heap is allocated merely to clone the already-funded parameter owner.
Failure is sticky for the WHOLE Invocation: a later base-only request cannot
recover after an extension error. "Base two unchanged" describes its schema,
producer and exact work bound, not permission to ignore a selected invocation
failure or reuse a successful base sub-result after another producer refused.

The outer distinct ExtensionWork branch publishes the fixed H006 text
`prelude extension producer work bound refused` by moving the existing paid
IdentityReservation buffers; a const length check proves it fits their original
capacity. No byte Refused is fabricated or rich error formatted after refusal.

Required controls: complete old/current indexes and wire over every existing
prefix; repeated same-invocation module pointer equality and unchanged producer
receipt; explicit none/foreign AST views; actual constructor plus final Drop in
one observer; exact/short/zero bytes/work, every acquisition refusal, sticky work,
foreign/restored byte tags, and the full ordinary source/HIR/diagnostic controls.
These source-authored controls are not runtime evidence or an allocation/peak
saving claim. The fixed base work model, corrected P and old receipts persist.

## Final-link lifetime decision

The earlier core budget ends at workspace_graph.rs4115..4162 before the returned
WorkspaceGraphBuild is constructed. Later final-link APIs accept no payer/lease;
retaining its Rc cannot reactivate that spent invocation. This packet therefore
optimizes only the actual live core extension path, not that final-link boundary.
A later paid final-link receiver needs its own explicit real caller authority.
