# Ordinary lexical PLAN cursor v1

Status: source-only OPT883 candidate. No compiler, runtime, physical improvement,
application fit or completion-row claim. Independent before-formation review and
focused qualification remain required.

The invocation-local comparison owner uses two named PLAN cursor fields. Each
next operation executes its complete forward body lexically. It constructs no
next function actual/formal transport or fallible compound return. Both yielded
Options and all actual borrowed/get/index/match/comparison payloads remain paid.
No observation reference escapes its pair/final match or survives a path swap.

The original forward-step and segment work requests execute in their original
order. The left PLAN operation completes before the right; flat/shared HIR is
read only after PLAN. Sorting, swap order, terminal/multiplicity comparison,
malformed preparation, all existing backing and shared-HIR preparation/next
payments remain unchanged. Only ephemeral proof paths are sorted. Original N,
work allowances, sticky selection, payer routes and budgets are unchanged.

A dynamic entry bank precedes each lexical cursor; dynamic segment banks cover
every loop test and payload, including the exhausted sentinel. Tail payloads
have their own dynamic bank. Possible segment slots are acquired before the
condition; the original segment work still precedes lookups. Tiny inputs can
pay more setup/sentinel bytes. Their actual totals require measurement.

The eight new primitive payment slots currently use the predecessor's narrow
lexical primitive-frame criterion: same invocation/function/budget, no overlap,
recursion or escape, ZST success and one terminal owned Diagnostic. Work-call
headers/Results are separately paid per entry/segment, not lent this credit.
Independent review must establish that this criterion covers the new payment
sites before adoption. If not, a genuinely retained reserve destination/API is
required; a paid-once flag or waived fresh Result would not satisfy this spec.

The complete immediate880 comparator with its original Cursor struct/methods,
constants, price expressions, sort body and dispatch condition is independently
compiled in comparison_owner/before_lexical_cursor.rs. Only namespace imports
and its nested test-module declaration are adapted; complete root/caller and
source preimages/inverses are retained in opt883-lexical-plan-cursor-20261017.
The older before_comparison/before_hir_compare/flat controls remain unchanged.
All original owning tests are preserved as an exact prefix of the test module.

New source-authored owners compare complete outputs/work/swap counts and all
work cuts/full Diagnostic fields, actual real receipt exact/short/zero/floor
and sticky/Drop frontiers, and actual paid/allocated/peak/freed/live totals.
Additional immutable-HIR/deep/foreign composition and original codec/native/

phase8/9 attribution remains diagnostic-only; gross cells do not imply net
