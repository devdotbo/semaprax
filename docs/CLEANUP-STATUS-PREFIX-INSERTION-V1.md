# Cleanup status prefix insertion v1

Status: authored private compiler optimization; qualification pending.

The ordinary metered status-source receiver may use prefix-certified insertion
for its own exact current status identity directory. Generic directory
construction, lookup, comparison, rotations and independent old status receivers
retain their complete original algorithms. No schema, admitted source, work cap,
byte cap, ordering, oracle scope or failure semantics gains authority here.

One paid Owner binds the exact immutable function, fresh directory address,
ReplayBudget address, current ClassifierLedger and next current source row.
Only the actual source-order status loop receives that owner. Binding, foreign
invocation and selected budget failure latch the first reason. Every insertion
authenticates it before certificate construction or mutation. Moving a receiver,
passing another function/budget/key row, or restoring an invocation after foreign
failure cannot reactivate it. The owner is destroyed before the directory moves
into the existing retained StatusSources token. It grants no budget or admission.

For zero/one keys, insertion retains the generic probe. Otherwise the specialized
probe pays before reading the held minimum key and traversing actual right
children to the maximum key. Two complete byte comparisons certify
p = min(LCP(query.expression, minimum.expression),
        LCP(query.expression, maximum.expression)).
Byte strings with one prefix form an ordered interval. Since StatusSourceId's
actual derived order is expression first and lane second, every held expression
key shares those p bytes with the query. UTF-8/NUL/empty/prefix/unknown keys and
all lanes receive the same proof; no textual ID parsing or assumed width occurs.
The certificate is confined to this immutable probe and never escapes, survives
insertion, or supplies semantic source authority.

The probe follows every original AVL node in the same order. Each node/key/child
read retains VISIT_UNITS=3 before dereference. New initialized/control fields
and assignments are charged explicitly before execution. Each complete or
suffix comparison pays the existing comparator model's ten scalar bookkeeping
units and min(byte lengths)-certified-prefix+1 byte-pair/end units. The complete
expression ordering receipt and equal-expression branch pay two additional
scalar units before execution. Only equal
expression bytes compare lanes, paying one existing numeric-field unit first.
No full expression Ord call rereads the skipped prefix. All work uses the same
ReplayBudget and phase text; no old debit is discounted or credited. Different
real operations mean different exact work/byte refusal frontiers, and shallow
or short-key probes can cost more. Semantic duplicate-before-unknown-before-
producer priority is unchanged wherever that algorithm's actual work suffices.

After a missing-key probe, the existing grow, append, links and rebalance sequence
is unchanged. The successful authorization receipt and inner/outer insertion Results receive
their exact three Layout fees per authenticated insertion before the probe.
Full new owner/search/comparison/Result carriers are paid through
the same byte owner before construction; exact old/new node backing remains the
existing reserve_vec protocol. Failure never grants post-refusal allocation,
new work allowance, fresh receiver or Drop credit. Ordinary detailed diagnostics
retain their existing funded-publication boundary.

The complete pre-prefix retained status receiver is compiled independently for
the status-fact reuse component equations as well as full old/current semantic,
wire, hostile, work-frontier and physical constructor-to-last-Drop controls.
No app-fit, exclusive original failure cause or measured saving follows from
source review; the unchanged retry/normalizer/backend/application owners decide
those results only after actual combined qualification.
